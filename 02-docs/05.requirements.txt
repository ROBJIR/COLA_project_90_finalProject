Final project - project requirements
-------------------------------------
Introduction
You are slowly approaching the end of the course. At the end you will have to prepare your own web application. From this article you will learn more about the preparation for the final project. We will discuss the required technologies and tell you how you should prepare a project plan. We will also describe some examples of projects.

What is there to do?
For the final project, you should develop a web application. It should use a database and present views using HTML code. Since we are on a backend course, we should focus more on how the application works, rather than on the appearance of our pages. Also, at least a few functionalities should be covered by unit tests. The topic of the application itself is arbitrary. Below you will find descriptions of some projects completed by our students.

Examples of final projects
The most interesting projects were usually created as a result of the desire to solve some real problem of a student or a person from the student's close environment. Below are some examples.

List of samples for testing
One of the students worked in a chemistry laboratory. In it, he was involved in the testing of various samples. All the samples that came in for testing were archived by an old secretary in a table drawn in a notebook. After a while the number of notebooks grew and data retrieval became very hard. The student decided to implement this "notebook" in the form of a web application. It significantly facilitated the storage and the search for data. It also enabled him to store additional information (e.g. pictures of samples). An interesting idea to extend this application would be to introduce QR code readers. This would allow it to be extended to a system for managing the whole laboratory in the future. Of course, within the final project, only basic functionalities were created, such as adding or searching for samples and storing photos. This is a great example of how to solve a real problem using software.

Financial management
It is well known that writing down expenses and planning a household budget is a great way to manage savings. You can do this in a notebook on a piece of paper, or using a spreadsheet. There are also many programs that make this task easier. Unfortunately, they often lack functionality or require a monthly fee (which is inconsistent with the idea of saving money). One of the students decided to implement such a program on his own. He had previously used a spreadsheet, so he knew exactly what functionality he would need. He made the application for himself, which does not mean that others will not find use for it as well. This is another example of how you can facilitate your work by creating an appropriate application.

Bookcrossing
Have you heard of bookcrossing or geocaching? One of the students decided to combine these two ideas by creating a web application.

Bookcrossing – the idea of donating books for free by leaving them in public places, as well as in places created on purpose, the so-called bookcrossing shelves (tables, bookcases, showcases), so that the finder can read them and pass them on.

Bookcrossing is an unconventional form of promoting books and reading, a mobile, virtual library - without its own premises, shelves or library cards. Source: [https://en.wikipedia.org/wiki/BookCrossing]

Geocaching (gr. geo – Earth, ang. cache /kæʃ/ – hiding place) – an outdoor game for users of GPS receivers, consisting in seeking the so-called geocaches previously hidden by other participants of the game. Hidden usually in interesting places, geocaches contain a logbook, in which the next finder signs, as well as small gifts for exchange. The location of a cache is communicated by its founder to the other game participants by entering geographical coordinates in one of the special Internet databases, the so-called geocaching services.

A student found that he had a lot of unnecessary books and a desire to do something interesting. He decided to independently implement a geocaching service. He created it based on the Django framework and OpenStreetMap (it's a free alternative to Google Maps, created on an open source license). After logging into the application, you could add your own books and display a map with books. After finding a book, it was possible to add it to a collection and contact the person who left it. A very interesting project using an external API (OpenStreetMap).

Which technologies to choose?
The project should be a web application written in Django. Moreover, it should use PostgreSQL database. Views should be created based on HTML language, and tests should use pytest framework. Of course, you can also use other modules or external tools. However, these four technologies are the bare minimum:

Django
PostgreSQL
HTML
pytest
Rules for passing the final project
In order for a project to be passed, it must meet several requirements.

It should be a web application, written in Django.
It must have a minimum of 5 models.
It must have a PostgreSQL database.
There should be at least 3 tables and 2 relationships between tables in the database.
The project must use at least one-to-many and many-to-many relationships.
There should be at least 5 views in the application.
The application should have at least one view available only to the logged-in user (using Django Auth system).
The application should have at least one form handled by the POST method.
Main application functionalities should be covered by tests (at least 3 unit tests written using pytest). There should be at least two tests for each view.
Each class and function should have at least a one-line documentation.
Of course, these are only minimal assumptions. If your project turns out bigger, or you will cover it with more tests, it will be great. If you add an endpoint API in addition to views - even better.

What will not affect the grade is the appearance of the application. We are on a backend course, so the performance of the application on the backend side is what is most important to us. Of course, if you have some time left, you can improve the appearance of your application, for example by using bootstrap. However, the performance of the program is the thing you should focus on first.

Summary
You still have some time left. Try your best to prepare for the project. A good plan is the basis for an efficient implementation. If you prepare everything properly, the project itself should go smoothly.

Good luck!

Zavedení
Pomalu se blížíte ke konci kurzu. Na jeho konci budete muset připravit vlastní webovou aplikaci.

a řekneme vám, jak byste měli připravit projektový plán. Popíšeme také několik příkladů projektů.

Co se dá dělat?
Pro závěrečný projekt byste měli vyvinout webovou aplikaci. Měla by používat databázi a prezentovat
pohledy pomocí HTML kódu. Vzhledem k tomu, že se věnujeme backendovému kurzu, měli bychom se více zaměřit na to,
 jak aplikace funguje, než na vzhled našich stránek. Také by alespoň několik funkcí mělo být pokryto jednotkovými testy.
 Téma samotné aplikace je libovolné. Níže naleznete popisy některých projektů, které naši studenti dokončili.

Příklady finálních projektů
Nejzajímavější projekty obvykle vznikaly jako výsledek touhy vyřešit nějaký reálný problém
studenta nebo osoby z blízkého okolí studenta. Níže uvádíme několik příkladů.

Seznam vzorků k testování
Jeden ze studentů pracoval v chemické laboratoři. Podílel se tam na testování různých vzorků.
Všechny vzorky, které přišly k testování, archivoval starý sekretář v tabulce nakreslené v sešitu.
Po čase počet sešitů rostl a vyhledávání dat se stalo velmi obtížným.
Student se rozhodl implementovat tento „sešit“ ve formě webové aplikace.
Výrazně to usnadnilo ukládání a vyhledávání dat. Umožnilo mu to také ukládat další informace (např. obrázky vzorků).
Zajímavým nápadem na rozšíření této aplikace by bylo zavedení čteček QR kódů. To by v budoucnu umožnilo její rozšíření na systém pro správu celé laboratoře.
V rámci závěrečného projektu byly samozřejmě vytvořeny pouze základní funkce, jako je přidávání nebo vyhledávání vzorků a ukládání fotografií.
Toto je skvělý příklad toho, jak řešit reálný problém pomocí softwaru.

Finanční řízení
Je dobře známo, že zapisování výdajů a plánování domácího rozpočtu je skvělý způsob, jak spravovat úspory.
Můžete to dělat v sešitu na papír nebo pomocí tabulky. Existuje také mnoho programů, které tento úkol usnadňují.
Bohužel jim často chybí funkcionalita nebo vyžadují měsíční poplatek (což je v rozporu s myšlenkou úspory peněz).
Jeden ze studentů se rozhodl implementovat takový program sám. Dříve používal tabulkový procesor, takže přesně věděl, jakou funkcionalitu bude potřebovat.
Aplikaci si vytvořil sám, což neznamená, že pro ni nenajdou využití i ostatní. Toto je další příklad toho, jak si můžete usnadnit práci vytvořením vhodné aplikace.

Bookcrossing
Slyšeli jste už o bookcrossingu nebo geocachingu ? Jeden ze studentů se rozhodl tyto dva nápady spojit vytvořením webové aplikace.

Bookcrossing – myšlenka darování knih zdarma jejich ponecháním na veřejných místech, ale i na místech k tomu účelu vytvořených, tzv. bookcrossingových regálech
(stoly, knihovny, vitríny), aby si je nálezce mohl přečíst a předat dál.

Bookcrossing je nekonvenční forma propagace knih a čtení, mobilní, virtuální knihovna – bez vlastních prostor, polic nebo čtenářských průkazů.
Zdroj: [https://en.wikipedia.org/wiki/BookCrossing]

Geocaching (řec. geo – Země, angl. cache /kæʃ/ – úkryt) – venkovní hra pro uživatele GPS přijímačů, spočívající v hledání tzv. geocachů,
které dříve ukryli ostatní účastníci hry. Geocachingy, obvykle ukryté na zajímavých místech, obsahují zápisník, do kterého se zapíše další nálezce,
a také drobné dárky k výměně. Polohu kešky sděluje její zakladatel ostatním účastníkům hry zadáním zeměpisných souřadnic do jedné ze speciálních internetových databází, tzv. geocachingových služeb.

Student zjistil, že má spoustu nepotřebných knih a touhu dělat něco zajímavého. Rozhodl se samostatně implementovat geocachingovou službu.
Vytvořil ji na základě frameworku Django a OpenStreetMap (jedná se o bezplatnou alternativu k Google Maps, vytvořenou na open source licenci).
Po přihlášení do aplikace bylo možné přidat vlastní knihy a zobrazit mapu s knihami. Po nalezení knihy bylo možné ji přidat do sbírky a kontaktovat osobu,
která ji zanechala. Velmi zajímavý projekt využívající externí API (OpenStreetMap).

Které technologie si vybrat?
Projekt by měl být webovou aplikací napsanou v Djangu . Navíc by měl používat databázi PostgreSQL .
Pohledy (views) by měly být vytvořeny v jazyce HTML a testy by měly používat framework pytest .
Samozřejmě lze použít i další moduly nebo externí nástroje. Tyto čtyři technologie jsou však nezbytným minimem:

    Django
    PostgreSQL
    HTML
    pytest

Pravidla pro úspěšné složení závěrečného projektu
Aby byl projekt schválen, musí splňovat několik požadavků.

    Mělo by se jednat o webovou aplikaci, napsanou v Djangu .
    Musí mít minimálně 5 modelů.
    Musí mít databázi PostgreSQL.
    V databázi by měly být alespoň 3 tabulky a 2 relace mezi tabulkami.
    Projekt musí používat alespoň vztahy typu jedna k mnoha a mnoho k mnoha.
    V aplikaci by mělo být alespoň 5 zobrazení.
    Aplikace by měla mít alespoň jeden pohled dostupný pouze pro přihlášeného uživatele (používá systém Django Auth).
    Aplikace by měla mít alespoň jeden formulář zpracovaný metodou POST.
    Hlavní funkce aplikace by měly být pokryty testy (alespoň 3 unit testy napsané pomocí pytest). Pro každý pohled by měly být alespoň dva testy.
    Každá třída a funkce by měla mít alespoň jednořádkovou dokumentaci.

Samozřejmě se jedná pouze o minimální předpoklady. Pokud se váš projekt rozroste nebo ho pokryjete více testy, bude to skvělé.
Pokud kromě zobrazení přidáte i API pro endpointy – ještě lépe.

Co neovlivní známku, je vzhled aplikace. Jsme v kurzu zaměřeném na backend, takže výkon aplikace na straně backendu je pro nás nejdůležitější.
Samozřejmě, pokud vám zbývá nějaký čas, můžete vzhled vaší aplikace vylepšit, například pomocí bootstrapu .
Výkon programu je však to, na co byste se měli zaměřit v první řadě.

Shrnutí
Ještě vám zbývá nějaký čas. Snažte se na projekt co nejlépe připravit. Dobrý plán je základem efektivní realizace. Pokud vše správně připravíte, měl by samotný projekt proběhnout hladce.
